About

PAMSI is a private peptide atlas built for MALDI Imaging Mass Spectrometry data of the extracellular matrix proteome. The current release (v1.0-data) contains high-quality peptide-spectrum matches (PSMs) and annotated fragment ions from:

  • Human Breast Cancer (Triple Negative) — 60 tissue samples
  • Mouse Cochlea — 16 samples

The interactive search engine allows mass-based querying (ppm tolerance), protein/gene filtering, and annotated spectrum viewing. All PSM and fragment tables were processed with FragPipe 24.0 (MSFragger).

Files were searched with FragPipe 24.0 (MSFragger) and pre-processed with an in-house R script available on GitHub (PAMSI-Database). Modified residues may appear as mass tags (e.g. N[115]) or as UNIMOD annotations (e.g. N[UNIMOD:7]).

Common mass-tag modifications

Notation Amino acid Unmodified residue ≈ Modified residue ≈ Δ mass Meaning UNIMOD
N[115] Asn (N) 114.04 115.03 +0.9840 Deamidated Asn UNIMOD:7
Q[129] Gln (Q) 128.06 129.04 +0.9840 Deamidated Gln UNIMOD:7
M[147] Met (M) 131.04 147.04 +15.9949 Oxidized Met UNIMOD:35
P[113] Pro (P) 97.05 113.05 +15.9949 Hydroxylated / oxidized Pro UNIMOD:35

Example: P[113] or P(15.9949) = proline with oxidation/hydroxylation (P[UNIMOD:35]) — frequent in collagen extracellular-matrix peptides.
