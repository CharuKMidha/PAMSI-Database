About

PAMSI is a private peptide atlas built for MALDI Imaging Mass Spectrometry data of the extracellular matrix proteome. The current release (v1.0-data) contains high-quality peptide-spectrum matches (PSMs) and annotated fragment ions from:

  • Human Breast Cancer (Triple Negative) — 112 tissue samples
  • Mouse Cochlea — 16 samples

The interactive search engine allows mass-based querying (ppm tolerance), protein/gene filtering, and annotated spectrum viewing.
